# CodeAlpha_taskbasic-chatbot

Basic Chatbot

Overview

This project is a simple rule-based chatbot developed in Python. It responds to predefined user inputs using conditional statements ("if", "elif", and "else"). It is designed for beginners to understand the basics of Python programming and chatbot development.

Features

- Greets the user
- Responds to simple predefined questions
- Uses "if", "elif", and "else" statements
- Uses functions and loops
- Exits the conversation when the user types bye

Requirements

- Python 3.x

How to Run

1. Clone or download this repository.
2. Open a terminal in the project folder.
3. Run the following command:

python chatbot.py

Example Conversation

You: hello
Bot: Hi! How can I help you?

You: how are you?
Bot: I am fine, thanks!

You: bye
Bot: Goodbye! Have a nice day.
